## 1. 閉じ込めスケーリング則の理論と統計

### 1.1 IPB98(y,2) スケーリング則の完全な形

**経験スケーリング則**（ITER Physics Basis, Chapter 2, Eq. 20）:

```
τ_E,th [s] = 0.0562 × I_p^0.93 × B_t^0.15 × P_loss^(-0.69) × n̄_e19^0.41 
              × M^0.19 × R^1.97 × ε^0.58 × κ^0.78
```

**パラメータ定義**:
- `I_p`: プラズマ電流 [MA]
- `B_t`: トロイダル磁場（プラズマ軸） [T]
- `P_loss`: 正味損失パワー = P_aux + P_α - P_rad [MW]
- `n̄_e19`: 線平均電子密度 [10^19 m^-3]
- `M`: イオン質量数（D-T混合で 2.5）
- `R`: 主半径（磁気軸位置） [m]
- `ε = a/R`: 逆アスペクト比
- `κ`: 伸長度（95%磁束面での値）

### 1.2 統計的根拠

**データベース**:
- 総データ数: N = 1310
- トカマク装置数: 15装置（JET, TFTR, JT-60U, DIII-D, ASDEX-U, C-Mod, 他）
- Root Mean Square Error: RMSE = 14.5%（対数空間での標準偏差）

**フィッティング手法**:
```
log(τ_E) = log(C_0) + Σ α_i log(x_i) + ε
```
- 多変量対数線形回帰
- 最小二乗法による指数α_iの決定
- 残差εの分布: ε ~ N(0, σ²), σ ≈ 0.145

**統計的不確実性**:
```
95%信頼区間: τ_E,predicted × exp(±1.96 × 0.145)
            = τ_E,predicted × (0.75, 1.33)
```

ITER予測（Baseline条件）:
```
τ_E,ITER = 0.0562 × 15^0.93 × 5.3^0.15 × 80^(-0.69) × 10^0.41
           × 2.5^0.19 × 6.2^1.97 × 0.323^0.58 × 1.7^0.78
         = 3.7 s

95%信頼区間: (2.8 s, 4.9 s)
```

### 1.3 物理的解釈

**指数の意味**:

1. **電流依存性**: `τ_E ∝ I_p^0.93 ≈ I_p`（ほぼ線形）
   - 理由: 電流 ↑ → 磁気シア ↑ → 乱流抑制 ↑
   - 理論: Drift-wave乱流の安定化（∂q/∂r増大）

2. **磁場依存性**: `τ_E ∝ B_t^0.15`（弱い依存）
   - 理由: B ↑ → Larmor半径ρ_i ↓ → 乱流スケール縮小
   - gyroBohm則予測: `χ ∝ ρ_i^2 ∝ B^(-2)`（実験は弱い）

3. **パワー依存性**: `τ_E ∝ P_loss^(-0.69)`（負の相関）
   - 理由: 高パワー → 高温度 → 乱流駆動力増大
   - 注意: これはL-modeからの外挿、H-modeでは緩和

4. **サイズ依存性**: `τ_E ∝ R^1.97 ≈ R^2`（極めて強い）
   - 理由: 大型化 → ρ*/a ↓ → 乱流相関長減少
   - これがITERの基本設計思想（大型化で閉じ込め確保）

### 1.4 無次元パラメータ表現

**gyroBohm理論との整合**:
```
Ω_i τ_E = F(ρ*, ν*, β, q, κ, ...)
```

**規格化パラメータ**:
- `ρ* = ρ_i / a`: 規格化Larmor半径（装置サイズ比）
- `ν* = ν_ii R / (ε^1.5 v_th,i)`: 規格化衝突周波数
- `β = 2μ_0 p / B^2`: プラズマベータ

**ITERの位置づけ**:
```
ρ*_ITER ≈ 0.002（既存装置の 1/3 ～ 1/5）
```
- 外挿リスク: 小型装置で見えない物理の出現可能性
- 緩和要因: JT-60Uでρ* ~ 0.003を一部カバー

## 2. MHD安定性理論：Troyon限界の導出

### 2.1 理想MHD平衡方程式

**Grad-Shafranov方程式**（円筒近似）:
```
Δ*ψ = -μ_0 R^2 dp/dψ - F dF/dψ
```
- `ψ`: ポロイダル磁束関数
- `p(ψ)`: 圧力分布
- `F(ψ) = R B_φ`: トロイダル磁場関数

**圧力駆動電流**:
```
j_φ = R dp/dψ + (1/μ_0 R) dF²/dψ
```

### 2.2 Troyon β限界の導出

**外部kink不安定性** (m/n = 1/1 mode):

摂動磁場 `δB_1`:
```
δW = (1/2μ_0) ∫ d³r [ |∇×δB_1|² - j·(δB_1×B*) ]
```

**不安定条件**: `δW < 0`

**臨界β**（Troyon et al., Plasma Phys. Control. Fusion 26, 209 (1984)）:
```
β_t,crit = C_Troyon × I_p / (a B_t)
```

**規格化表現**:
```
β_N = β_t(%) × a(m) × B_t(T) / I_p(MA) ≤ C_Troyon
```

### 2.3 Troyon係数の理論値と実験値

**理論計算**（理想MHDコード：DCON, GATO, PEST）:

| 条件 | C_Troyon | 根拠 |
|------|---------|------|
| 円形断面、li=1.0 | 2.8 | 理論計算 |
| D型断面、κ=1.7, δ=0.33 | 3.2 | 形状効果 |
| 抵抗壁安定化 | 3.5-4.0 | 理想壁近傍 |

**内部インダクタンス補正**:
```
β_N,limit = C_Troyon × (1 - l_i / 3)
```

**li（内部インダクタンス）の定義**:
```
l_i = (2 / μ_0 I_p² R_0) ∫ d³r B_p²
```
- `l_i = 1.0`: 均一電流分布（オフアクシスピーク）
- `l_i = 0.5`: 中心ピーク電流分布（好ましい）

**ITER設計値**:
```
β_N,limit = 3.5 × (1 - 0.8/3) = 3.5 × 0.733 = 2.57
```

### 2.4 ITER運転点の選定

**baseline条件**:
```
β_t = 2.5%, a = 2.0 m, B_t = 5.3 T, I_p = 15 MA

β_N = 2.5 × 2.0 × 5.3 / 15 = 1.77
```

**安全マージン**:
```
Margin = 1 - β_N / β_N,limit = 1 - 1.77 / 2.57 = 0.31 (31%)
```

**設計思想**:
- 理論限界の70%で運転（保守的設計）
- MHD不安定性に対する余裕確保
- NTM制御の成功を前提としない

## 3. Neoclassical Bootstrap電流の理論

### 3.1 Banana軌道と粒子捕捉

**トロイダル磁場構造**:
```
B(R, θ) ≈ B_0 (R_0 / R) ≈ B_0 (1 - ε cos θ)
```
- `ε = r / R_0`: 局所逆アスペクト比

**捕捉粒子条件**:
```
v_‖² / v² < ε
```
- 捕捉粒子分率: `f_t ≈ 1.46 √ε ≈ √(2ε)`

### 3.2 Bootstrap電流の物理機構

**バナナ軌道の非対称性**:
- 内側通過 → 高磁場側
- 外側通過 → 低磁場側
- 非対称性 → 正味トロイダル電流

**Ware pinch効果**との競合:
- Ware: ポロイダル電場による粒子駆動
- Bootstrap: 圧力勾配による粒子機構

**正味Bootstrap電流**:
```
j_bs / B = C_bs × (dp/dr) / B²
```

### 3.3 定量的表現（Sauter et al.モデル）

**完全式**（Phys. Plasmas 6, 2834 (1999)）:
```
f_bs = (I_bs / I_p) = C_1(ν*_i) × β_p × ε^0.5 × [L_31 + L_32 (T_i/T_e) + L_34 α]
```

**パラメータ**:
- `C_1(ν*_i)`: コリジョナリティ関数
- `β_p = 2μ_0 <p> / <B_p²>`: ポロイダルベータ
- `ν*_i = ν_ii q R / (ε^1.5 v_th,i)`: 規格化衝突周波数
- `α = -R q² (dβ/dr) / β`: 圧力プロファイルパラメータ

**簡略式**（ITER解析用）:
```
f_bs ≈ 1.32 × [1 + 1.4 / (ν*_eff + 0.7)] × β_p × ε^0.5
```

### 3.4 ITER条件での計算

**典型値**:
```
β_p = 0.7, ε = 0.32, ν*_eff = 0.05
```

**Bootstrap分率**:
```
f_bs = 1.32 × [1 + 1.4 / 0.75] × 0.7 × √0.32
     = 1.32 × 2.87 × 0.7 × 0.566
     = 1.50 (150%の overestimate)
```

**現実的補正**（saturation効果）:
```
f_bs,actual ≈ 0.25 ～ 0.30 （全電流の25-30%）
```

**Hybrid scenario**（高β_p運転）:
```
β_p = 1.2, f_bs ≈ 0.40 ～ 0.50
```

## 4. NTM発展のModified Rutherford方程式

### 4.1 古典的Rutherford方程式

**磁気島幅の発展**:
```
τ_R × dw/dt = r_s × Δ'
```

**パラメータ定義**:
- `w`: 磁気島幅（separatrix間距離） [m]
- `r_s`: 有理面半径（q = m/n） [m]
- `Δ'`: テアリング安定性パラメータ [m^-1]
- `τ_R = μ_0 r_s² / η_‖`: 抵抗拡散時間 [s]

**Δ'の定義**:
```
Δ' = (d ln ψ_1 / dr)|_out - (d ln ψ_1 / dr)|_in
```
- 有理面内外での対数微分の跳び

### 4.2 Neoclassical効果の追加

**Bootstrap電流の欠損**（島内部で圧力勾配 → 0）:
```
τ_R × dw/dt = r_s Δ' + a_bs × β_p × w
```

**係数a_bs**:
```
a_bs = (5.1 / √ε) × (r_s / R_0) × (r_s / L_q)
```
- `L_q = q / (dq/dr)`: 磁気シア長

### 4.3 安定化項

**1. Ion polarization current**（Hegna & Callen, Phys. Plasmas 4, 2940 (1997)）:
```
j_pol = (ω_p / Ω_i) × (dφ_1 / dr)
```
- 項: `-a_pol / w²`（島幅が小さい時に安定化）

**2. Cross-field transport**（Fitzpatrick, Phys. Plasmas 2, 825 (1995)）:
```
κ_⊥ = χ_⊥ / (τ_‖ v_th²)
```
- 項: `-a_χ / w`（輸送による安定化）

**完全Modified Rutherford方程式**:
```
τ_R × dw/dt = r_s Δ' + (a_bs β_p - a_pol/w² - a_χ/w) × w - a_ECCD × j_ECCD / w
```

### 4.4 閾値島幅

**不安定化条件**:
```
dw/dt > 0  ⇔  w > w_threshold
```

**臨界島幅**:
```
w_threshold² = a_pol / (a_bs β_p - a_χ - r_s Δ')
```

**ITER推定値**（m/n = 3/2モード、r_s ≈ 1.5 m）:
```
w_threshold ≈ 2-5 cm
```

### 4.5 ECCD安定化

**局所電流駆動による安定化項**:
```
Δj_ECCD(r) = (η_CD × P_ECCD / R_0) × exp[-(r - r_s)² / (2Δr_CD²)]
```

**必要ECCD パワー**（島幅を減少させる条件）:
```
P_ECCD,required > (w × r_s / (a_ECCD × η_CD)) × (a_bs β_p - Δ')
```

**数値例**（ITER, w = 10 cm, r_s = 1.5 m）:
```
a_bs ≈ 4.0, β_p = 0.7, Δ' ≈ 0 (marginally stable)

P_ECCD,required > (0.1 × 1.5 / (10 × 0.2)) × 4.0 × 0.7
                ≈ 2.1 MW
```

**実際の設計値**: P_ECCD,NTM ≈ 3-5 MW（安全マージン含む）

## 5. ECCD理論：Fisch-Boozer効率

### 5.1 準線形拡散理論

**運動論的波動吸収**:
```
∂f/∂t = ∂/∂v_‖ [D_QL ∂f/∂v_‖ + (F_QL - C) f]
```

**準線形拡散係数**:
```
D_QL = (π e² / m_e² ω²) Σ_n |E_n|² δ(ω - n ω_ce - k_‖ v_‖)
```

**共鳴条件**:
```
ω - n ω_ce - k_‖ v_‖ = 0
```

### 5.2 Current drive効率（Fisch理論）

**電流駆動係数**:
```
η_CD = (n_e R_0 I_ECCD) / P_abs
```

**単位**: `[10^20 A·m·W^-1]`または`[A/(W·m^-2)]`

**Fisch-Boozer効率**（高温極限）:
```
η_CD ≈ (e / m_e c²) × (Z_eff + 3) / [Z_eff + 1] × (T_e / m_e c²)
    ≈ 0.2 × [(Z_eff + 3) / (Z_eff + 1)] × (T_e [keV] / 511)
```

**ITER条件**（T_e = 20 keV, Z_eff = 1.5）:
```
η_CD ≈ 0.2 × (4.5 / 2.5) × (20 / 511)
     ≈ 0.2 × 1.8 × 0.039
     ≈ 0.014 [10^20 A·W^-1·m^-2]
```

### 5.3 実験との比較

**規格化効率** (Chapter 6, Table):
```
η_20 = (n_e20 R_0 I_CD) / P_launched
```

| トカマク | Te [keV] | η_20実験 | η_20理論 | 比率 |
|---------|---------|---------|---------|------|
| RTP | 3 | 0.10 | 0.12 | 0.83 |
| DIII-D | 5 | 0.15 | 0.18 | 0.83 |
| JT-60U | 10 | 0.25 | 0.28 | 0.89 |
| **ITER予測** | 20 | **0.30** | 0.35 | 0.86 |

**結論**: 理論は実験を15%程度過大評価（保守的設計に有利）

### 5.4 トロイダル角度依存性

**最適角度**（最大効率）:
```
tan θ_opt = (n_‖ / n_⊥)_opt ≈ √(ω / ω_ce - n) / √n
```

**ITER（n = 1, ω_ce = 170 GHz）**:
```
θ_opt ≈ 20°～ 40°
```

**Steering範囲**: θ = 0° ～ 60°（リアルタイム制御可能）

## 6. Sawtooth不安定性とKadomtsev再結合

```
q(r) < 1  かつ  s_1 < s_crit
```

```
s = (r / q) × (dq / dr)
```

```
s_crit ≈ 0.3 ～ 0.5
```

```
Δψ = ψ_core - ψ_edge = 0
```

**混合半径** (mixing radius):
```
r_mix ≈ r_q=1 × √2
```

```
ΔT_e / T_e,0 ≈ (r_q=1 / a)²
```

```
ΔT_e / T_e,0 ≈ (0.3 / 2.0)² = 0.0225 (2.25%)
```

### 6.3 α粒子安定化効果

**α圧力勾配**:
```
∇p_α ∝ ∂P_fusion / ∂r
```

## 7. Greenwald密度限界の物理

### 7.1 経験則

**Greenwald limit**（Nucl. Fusion 28, 2199 (1988)）:
```
n̄_G [10^20 m^-3] = I_p [MA] / (π a² [m²])
```

**ITER**:
```
n̄_G = 15 / (π × 2.0²) = 1.19 × 10^20 m^-3
```

### 7.2 物理機構（複数の説がある）

**仮説1: MARFE（多面放射崩壊）**:
```
P_rad = n_e² × L_Z(T_e)
```
- 高密度 → 放射増 → 温度低下 → さらなる放射増（正帰還）

**仮説2: Edge cooling**:
```
Q_edge = P_SOL / (n_e × A_edge) < Q_crit
```
- エッジ熱流束不足 → H-mode崩壊

**仮説3: MHD coupling**:
```
q_edge × n_e / n_G > 1  → MHD不安定
```

### 7.3 ITER運転点

**baseline**:
```
n̄_e / n̄_G = 1.0 × 10^20 / 1.19 × 10^20 = 0.84
```

**マージン**: 16%

## 8. 定量的制約条件の導出

### 8.1 Q値の定義と要求

**核融合増倍率**:
```
Q = P_fusion / P_aux
```

**エネルギーバランス**:
```
W_th / τ_E = P_aux + P_α - P_rad
```

**α加熱分率** (D-T反応):
```
P_α = 0.2 × P_fusion = 0.2 × Q × P_aux
```

**定常状態**:
```
P_aux × (1 + 0.2 Q) = W_th / τ_E + P_rad
```

### 8.2 Q=10達成条件

**条件式**:
```
τ_E ≥ W_th / [P_aux × (1 + 0.2 Q) - P_rad]
```

**ITER数値**（Q = 10目標）:
```
W_th = 350 MJ, P_aux = 50 MW, P_rad = 30 MW, Q = 10

τ_E,required ≥ 350 / [50 × (1 + 2) - 30]
             = 350 / [150 - 30]
             = 350 / 120
             = 2.92 s
```

**IPB98(y,2)予測**: τ_E = 3.7 s

**マージン**:
```
Margin = (3.7 - 2.92) / 2.92 = 0.27 (27%)
```

### 8.3 核融合出力の定量化

**DT反応率**:
```
R_DT = n_D × n_T × <σv>
```

**反応度パラメトリゼーション**（Bosch & Hale, Nucl. Fusion 32, 611 (1992)）:
```
<σv> [m³/s] = C_1 × T^(-2/3) × exp(-C_2 / T^(1/3))

C_1 = 1.17 × 10^-24, C_2 = 19.94, T [keV]
```

**T_i = 20 keV**:
```
<σv> ≈ 1.1 × 10^-22 m³/s
```

**核融合パワー密度**:
```
P_fusion / V = (1/4) × n_D × n_T × <σv> × E_fusion
             = (1/4) × (n_e/2)² × <σv> × 17.6 MeV

n_e = 1.0 × 10^20 m^-3:

P_fusion / V = 0.25 × (5 × 10^19)² × 1.1 × 10^-22 × 17.6 × 1.6 × 10^-13
             = 1.23 × 10^6 W/m³
```

**総核融合出力**（V = 837 m³）:
```
P_fusion = 1.23 × 10^6 × 837 = 1.03 × 10^9 W ≈ 1 GW
```

**実際の設計値**: 400-500 MW（保守的、部分燃焼）

### 8.4 β限界からの出力上限

**ポロイダルβ**:
```
β_p = 2μ_0 <p> / <B_p²>
```

**トロイダルβ**:
```
β_t = 2μ_0 <p> / B_0²
```

**関係式**:
```
β_t = β_p × (B_p / B_0)² = β_p / (2 × I_p / (a × B_0))²
```

**ITER**:
```
β_t = β_p × (μ_0 I_p / (2π a B_0))²
    = 0.7 × (4π × 10^-7 × 15 × 10^6 / (2π × 2.0 × 5.3))²
    = 0.7 × (2.83 × 10^-1)²
    = 0.056 (5.6%)
```

**実際運転点**: β_t = 2.5%（限界の45%）

### ITER運転の成立条件

**1. β限界制約**:
```
β_N = 1.77 < 2.57  ✓（31%マージン）
```

**2. 密度限界制約**:
```
n_e / n_G = 0.84 < 1.0  ✓（16%マージン）
```


```
P(success) = P(H ≥ 1.0) × P(NTM制御可) × P(Disruption回避)
           ≈ 0.80 × 0.70 × 0.90
           ≈ 0.50 (50%)
```

**この50%という数値が、ITER建設の科学的根拠である。**
